# Gallery generator

Run `scripts/generate-gallery-figures` from the repository root. SVGs are written
to `docs/gallery`, alongside the repository-browsed `GALLERY.md`.

Use `--check` to recompute and compare against committed SVGs without rewriting
them. Pass one or more SVG filenames to run only selected fixtures. A failed
geometry operation is reported with its filename and produces a nonzero exit
status; other fixtures still run.
The generator validates SVG root dimensions and verifies that its complete
filename inventory matches the image links in `GALLERY.md`.

The F# fixtures follow these Gleam sources:

- `test/svg_path_gallery_test.gleam`: strokes, offsets, hulls, cut radiator;
- `test/svg_path_figure_eight_correspondence_fixture.gleam`: the current display
  heuristic pairing endpoints of the two untrimmed walks (not certified provenance);
- `test/svg_path_convex_hull_gallery_fixture.gleam`: the three figure-eight hulls;
- `examples/readme_arrangement_figures/src/arrangement_csg_figures.gleam`:
  the twelve Boolean/arrangement studies.

`Inputs` contains source geometry, not computed output. `Snapshots` contains
three explicitly archived illustrations which the Gleam generator also reads
from pre-rendered SVGs: second-offset arrangement, text coil, text decaying spiral.
They are not claimed to be generated by F#.

The renderer computes each panel's framing from its actual geometry. Every new
SVG has root dimensions, a viewBox, and an exact full-viewBox white background.
The executable is non-packable and is not referenced by the library package.

Recursive dashes retain Gleam's `(92,154)` source placement before geometric
operations, rather than merely translating at rendering time. This matters
for reproducing floating-point-sensitive stroke fixtures. Unlike the old Gleam
display helper, this generator reports a failed second-level stroke rather
than silently omitting it.
